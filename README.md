# Smart Notes Generator

Smart Notes Generator is an AI-powered PDF-based study material generator designed to transform documents and study materials into structured notes, quizzes, and flashcards.

## Project Structure

```text
smart-notes-generator/
├── frontend/     # React + Vite + Tailwind CSS web interface
├── backend/      # Node.js + Express REST API
├── ml-service/   # Python-based NLP/ML service
├── README.md     # Project documentation
└── .gitignore    # Git ignore rules
```

## Core Components

- **Frontend**: Web interface built with React, Vite, and Tailwind CSS.
- **Backend**: RESTful API service built with Node.js and Express.
- **ML Service**: Python service handling PDF processing and NLP/ML capabilities for content generation.

## Eventual Features

- PDF text and layout extraction
- Structured notes generation
- Interactive quizzes generation
- Study flashcards generation
